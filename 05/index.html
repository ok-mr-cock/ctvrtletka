Vrcholový a obecný tvar

Vzorec k použití

(x + s)² = x² + 2s·x + s²

Pozor na znaménko: v závorce x − 3 je s = −3, v závorce x + 3 je s = 3.

x² + k·x = (x + k/2)² − (k/2)²

Číslo k je to, které stojí u x. Polovina k se píše do závorky i se znaménkem, její druhá mocnina se odečítá.
